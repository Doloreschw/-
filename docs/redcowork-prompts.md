# 一物千景 · 升级指令（分 5 步发给 REDcowork）

用法：每一步单独发一条消息，等它做完、你在页面上点一遍确认没问题，再发下一步。不要一次全发，出错了不好定位，也更费额度。
第 2 步内容量最大，建议先只做「便携保温杯」一个品类，额度够再扩展到其他品类。

---

## 第 1 步：先让它读懂现有项目（只读，不改代码）

```
请先通读当前项目的全部文件（index.html、shell.js、styles.css、data.js、market.js、app.js），不要修改任何代码。读完后用 10 行以内告诉我：
1. data.js 里 PRODUCTS[].scenes 每个场景有哪些字段；
2. app.js 里星图、场景抽屉、策划页分别由哪些函数渲染；
3. 页面现在有几个步骤视图。
后面我会分几步让你升级功能。所有修改都要遵守三条规则：
- 不改动已有的数据来源标注（机构数据 / 京东实采 / AI 评估），新增内容也要按这三类标注；
- 不编造任何统计数字、点赞数、销量、真实博主或真实笔记；
- 每一步改完都要保证原有流程（首页 → 品类档案 → 场景星图 → 策展清单）还能完整跑通。
```

## 第 2 步：把场景拆得更细

```
现在升级「场景」的颗粒度。目前每个场景只有“一句话人群 + 兴趣圈层”，太粗。请改成三层结构，并给每个场景加上细分维度标签。

【三层结构】
兴趣圈层（已有 6 个：职场通勤、校园考试、亲子家庭、户外山野、独居自处、送礼心意）
→ 细分人群（每个圈层 2–3 个，写清身份，例如“刚入职的应届生”“远程办公的自由职业者”）
→ 具体瞬间（每个细分人群 1–2 个，写清在什么时刻、什么地方、发生了什么）

【每个场景新增字段】
- segment：细分人群名称
- when：时间段，从这些里选：清晨、通勤路上、上午工作、午休、下午、下班后、深夜、周末、节假日、季节性
- where：地点，从这些里选：家、宿舍、办公室、图书馆、通勤交通、户外、旅途、医院、车里、他人家中
- mood：当下情绪，从这些里选：焦虑、疲惫、孤独、期待、仪式感、愧疚、被照顾、想犒劳自己
- trigger：触发这次需求的具体事件，一句话
- role：购买角色，三选一：自己用、送给别人、替家人买
- age：年龄段，从 18-24、25-30、31-40、41+ 里选

【数量】
先只做「便携保温杯」：从现有 12 个场景扩展到 24 个左右，原有 12 个保留并补齐新字段。其他三个品类先只给原有场景补齐新字段，不扩数量。

【页面改动】
1. 场景星图的筛选区，在“兴趣圈层”和“年龄段”之外，增加“时间段 / 地点 / 情绪 / 购买角色”四组筛选标签，可以多组同时生效。
2. 星图上的点和列表卡片，悬停或展开时显示“细分人群 · 时间段 · 地点”。
3. 场景详情抽屉顶部，用一行小标签显示 segment / when / where / mood / role / age，下方新增“触发事件”一栏。
4. 品类档案页“聚焦人群与年龄段”卡片里，再加一个“按细分人群统计”的小条形图，点击可跳转到星图并筛好。
5. 这些新维度都属于 AI 评估，标签沿用紫色的「AI 评估」标注。

【质量要求】
每个新场景都要具体到“某类人在某个时刻因为某件事需要它”，不要写成“适合上班族”这种空泛描述；同一圈层下的场景之间不能只是换个说法。
```

## 第 3 步：加入「爆款话术拆解库」

```
新增一个「话术拆解库」模块，作为场景详情抽屉里的新标签页，并在顶部导航加一个独立入口“话术库”。用途是：把小红书上常见的爆款写法拆成可以套用的公式，让商家速成。

【数据结构】
新建 copy-lib.js，定义 window.COPY_LIB，分四类：
1. titles（标题公式）
2. openings（开头钩子）
3. bodies（正文结构）
4. endings（结尾互动）

每条公式包含这些字段：
- id、name（公式名）
- formula：一句话结构，例如“【身份】+【时刻】+【反常结果】”
- why：为什么有效，一句话
- fit / notFit：适合 / 不适合的商品或场景
- template：带【填空】的模板
- source：出处标注（见下）

【标题公式】
以下 7 种归纳自公开文章《小红书爆款标题玩法01：你一定要学会的情绪化表达》（李子木说运营，人人都是产品经理，2024-03-13），source 写这篇文章的名称，并在库页面底部附原文链接 https://www.woshipm.com/?p=6009458 ：
口语冲突式、惊讶反问式、悬念提示式、只讲一半吐槽式、反常认知式、身边案例可信式、游戏养成式（生存指南 / 养成计划）。
另外再补充 5 种电商种草常用写法，source 标为「本工具归纳」：身份 + 时刻代入式、前后对比式、数字清单式、价格锚点式、避坑反向式。

【开头钩子】（source 标为「本工具归纳」）
场景画面开头、痛点直击开头、反常结论开头、提问开头、真实小事开头。

【正文结构】（source 标为「本工具归纳」）
痛点 → 尝试 → 转折 → 结果；清单式（3–5 点）；前后对比；一天的时间线；避坑指南（踩过的坑 → 怎么选）。

【结尾互动】（source 标为「本工具归纳」）
提问求经验、二选一投票、收藏提示、晒同款邀请。

【速成卡】
话术库页面顶部放一张“速成卡”，自动统计并显示：“X 种标题 × Y 种开头 × Z 种正文结构 × W 种结尾 = 可组合 N 套写法”，数字由 COPY_LIB 的条数实时计算，不要写死。

【重要规则】
- 不要编造“某篇爆款笔记点赞 10 万”之类的数据，也不要虚构真实博主或真实笔记。
- 所有示例文案都是针对本工具场景的仿写，必须标注「AI 仿写示例」。
- 页面上写明：公式是对公开拆解文章和常见写法的归纳，效果会随平台内容风格变化，需要持续测试。
```

## 第 4 步：让每个场景都能“套公式生成文案”

```
把话术库和场景连起来。在场景详情抽屉里新增“写文案”标签页：

1. 顶部四个下拉框：标题公式、开头钩子、正文结构、结尾互动。默认值按场景自动推荐：
   - mood 是“焦虑/疲惫/孤独”的，默认用“痛点直击开头 + 痛点→尝试→转折→结果”；
   - role 是“送给别人”的，默认用“身份 + 时刻代入式标题 + 真实小事开头”；
   - 拥挤度 y ≥ 65 的红海场景，默认用“反常认知式”或“避坑反向式”标题，用来做差异化。
2. 根据场景字段（segment、when、where、mood、trigger、pains、hooks、searches）和选中的公式，用模板拼出一篇完整笔记：1 个标题、正文约 200–300 字、结尾 1 句互动、5 个话题标签（从 searches 里提取）。
3. 拆解视图：生成的笔记里，每一段用浅色底标出它对应哪个公式的哪个部分（例如“钩子”“痛点”“转折”），鼠标悬停显示该公式的 why。
4. “换一套”按钮：随机换一组公式重新生成，方便商家对比。
5. “加入策展清单”时，把当前选中的这套文案一起带进第 04 步策划页，策划页每个场景显示完整笔记，“复制全部文案”也包含完整笔记。
6. 生成的文案统一标注「AI 仿写示例」。
```

## 第 5 步：合规检查和最终自检

```
最后两件事：

【1. 文案合规检查】
在“写文案”标签页的笔记下方加一个自动检查条，扫描生成的文案和用户手动修改后的文案，命中就高亮并给出替换建议：
- 极限用语：依据《广告法》第九条，广告不得使用“国家级”“最高级”“最佳”等用语。词表包括：最、第一、顶级、极致、绝对、100%、全网最低、国家级、销量冠军。
- 疾病治疗功效：依据《广告法》第十七条，除医疗、药品、医疗器械广告外，广告不得涉及疾病治疗功能。词表包括：治疗、治愈、根治、药效、消炎、抗癌、助眠治失眠。
- 页面上注明：词表只覆盖常见风险，不能代替平台审核和法律意见。

【2. 自检】
从评委第一次打开链接的视角，完整走一遍：
首页 → 选“便携保温杯” → 品类档案 → 场景星图（试一下新增的四组筛选）→ 点开一个场景 → 写文案（换一套、看拆解视图）→ 加入清单 → 再加两个场景 → 生成策划 → 复制全部文案 → 打开话术库看速成卡。
再用手机宽度（390px）走一遍。列出所有报错、空白、按钮无响应、文字溢出的地方，并修复。修完后告诉我改了哪些文件。
```
